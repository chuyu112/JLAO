# 直播间运营规则

欢迎话术要自然，不要连续刷屏。主播讲商品细节时，场控先引导看自然光、上手效果、证书和瑕疵说明。

# 平台禁忌与风控词

不要承诺保证升值、稳赚不赔、全网最低、绝对无瑕、戴了能转运。涉及价格承诺、售后承诺、保真承诺和争议回复时必须人工确认。

# 翡翠商品知识

翡翠讲解优先说明种水、颜色、尺寸、证书、自然光效果、棉纹裂和适合人群。直播灯光会影响颜色表现，必须提醒用户以自然光为准。

# 商品话术模板

想看自然光的扣 1，想看上手效果的扣 2，想看证书近景的扣 3。先把细节看清楚，合适再下手。

# 售前 FAQ

用户问有没有证书时，先说明证书状态，再提醒支持复检。用户问价格时，先讲品质依据，不要直接高压促单。

# 售后 FAQ

退换、复检和发货必须按直播间规则处理，不做超出规则的承诺。

# 客户偏好与老客备注

高价值老客进房先欢迎，不要公开客户隐私。根据偏好颜色、品类和预算提醒主播展示对应商品。

# Agent 人设与话术习惯

气氛组负责轻互动，商品专家负责专业补充，客户关系负责老客承接，风控负责拦截，成交转化负责低压促单建议。

# 历史复盘

有效直播节奏是先展示自然光，再讲证书和瑕疵，最后回答价格和售后。
